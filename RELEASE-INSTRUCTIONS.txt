PIXEL OVERLAY — WINDOWS INSTALLER
=================================

Install
1. Download PixelOverlay-Setup.exe from the official GitHub Releases page.
2. Close Xbox Game Bar if it is currently open.
3. Run PixelOverlay-Setup.exe and click Install.
4. When installation finishes, press Win+G, open Widgets, and select Pixel Overlay.

The setup program:
- Checks for 64-bit Windows 10 version 2004 (build 19041) or later.
- Adds the included publisher certificate to the current Windows user's Trusted People store.
- Downloads the signed App Installer manifest and installs Pixel Overlay with its required x64 framework dependencies.
- Registers the stable App Installer update source.

Updates
- Windows checks for updates when the app is launched (at most once every 12 hours).
- An automatic background update task is also registered. Windows schedules these checks periodically when background servicing is available.
- Update checks are controlled by Windows App Installer and may be delayed while the device is offline or the app is in use.
- Future updates keep the same package identity and signing certificate. Users do not need to download the setup program again.

Security and reputation
This beta is signed with a persistent self-signed Code Signing certificate. The setup imports the matching public certificate for the current Windows user. Windows SmartScreen may still show an unrecognized-app warning because the certificate is not issued by a public commercial certificate authority and the installer has no Microsoft Store reputation. Only run releases downloaded from the official repository:
https://github.com/valenokw2/bobsiwww222zxcv/releases

Requirements
- 64-bit Windows 10 version 2004 (build 19041) or later.
- Xbox Game Bar installed and enabled.
- Internet access during installation and update checks.

Uninstall
Open Windows Settings > Apps > Installed apps, find Pixel Overlay, and choose Uninstall.
The app's local settings and image library are kept by Windows package removal unless the user removes its app data separately.

Troubleshooting
- If the package publisher cannot be verified, confirm that the setup completed and installed the included certificate for the same Windows user.
- If the installer reports a failure, inspect:
  %LOCALAPPDATA%\PixelOverlay\Installer.log
- If Xbox Game Bar was not detected, install or enable Xbox Game Bar from Microsoft Store, then press Win+G.
- If the widget list does not refresh, fully close and reopen Xbox Game Bar.
